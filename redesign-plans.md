# Website Redesign Plans

## Redesign 1: Editorial Grid

Index layout: A wide, centered editorial grid with a two-column hero. The left column features the name, bio, and project highlights. The right column hosts contact links and a short “notes” callout. Below, blog posts are listed in a clean list with thin separators, a slim date column, and titles aligned to a strong left edge.

Slug layout: A two-column reading layout. The left sticky sidebar shows the date, reading time, project link, and a vertical table of contents. The main column carries a large serif title and a subtle drop cap on the first paragraph, with a tighter text column and generous white space.

Fonts: Headings in Noto Serif SC, body copy in DM Sans, code in IBM Plex Mono.

Colors: Off-white background (#f7f3ee), charcoal text (#1f1a17), accent maroon (#8b1e3f), muted brown-gray (#6f625b), hairline borders (#e6ded6).

Other: Thin dividers, mild letter-spacing, and a paper-like feel.

## Redesign 2: Minimal Mono

Index layout: Single-column minimal list, monochrome. A concise header shows the name and a one-line bio. Blog posts appear in a terminal-like list with compact dates, all-caps metadata, and precise spacing. Projects are reduced to a compact, readable list above posts.

Slug layout: A streamlined reading column. Metadata row (date and reading time) appears above the title. Table of contents is a horizontal, wrap-friendly nav below the title. The content column is tight with consistent mono rhythm.

Fonts: IBM Plex Mono everywhere.

Colors: Clean white background, near-black text (#111827), accent green (#22c55e), muted gray (#9ca3af), borders (#e5e7eb).

Other: Minimal rules, consistent monospace grid feel, and precise spacing.

## Redesign 3: Pastel Cards

Index layout: Soft gradient background with a floating hero card for the intro and a responsive grid of post cards. Each post card includes a date pill, title, and subtle hover lift. Projects are grouped into a companion card with rounded corners.

Slug layout: A centered white content card with large rounded corners and shadow. On desktop, a light aside holds the table of contents, with sticky positioning. Metadata is displayed as soft badges above the title.

Fonts: Headings in Inter Tight, body copy in DM Sans, code in IBM Plex Mono.

Colors: Lavender-to-peach background gradient (#f7f3ff to #fff1f2), card white, accent indigo (#6366f1) with teal highlights (#14b8a6), muted lavender-gray (#8b88a0).

Other: Rounded UI, soft shadows, pastel highlights.

## Redesign 4: Dark Terminal

Index layout: Dark background with a faux terminal window containing the bio and project list. Posts are displayed as “command output” with green prompt accents and dim metadata. Links feel like commands.

Slug layout: Terminal header bar with window controls and metadata. Content sits in a dark panel with a left-hand TOC that resembles terminal navigation. Code blocks and inline code blend into the terminal aesthetic.

Fonts: Google Sans Code for everything.

Colors: Background (#0b0f14), text (#e5e7eb), accent cyan/green (#22d3ee), muted slate (#6b7280), borders (#1f2937).

Other: Terminal chrome, subtle glow on links.

## Redesign 5: Split Gallery

Index layout: Split-screen structure with a large left column for name, bio, and headline copy, and a right column for projects and posts. A cobalt accent block anchors the top-right corner. Posts are listed with dotted separators and bold titles.

Slug layout: A full-width title band with oversized typography, followed by a centered content column. The table of contents appears as a vertical rail on the right with a slim border and active highlight.

Fonts: Headings in Inter Tight, body copy in Noto Serif SC, code in IBM Plex Mono.

Colors: Warm off-white background (#fdfcf9), text (#111827), accent cobalt (#2563eb), warm highlight (#f59e0b), borders (#e5e7eb).

Other: Strong typographic hierarchy, visible rails, and clean geometry.
